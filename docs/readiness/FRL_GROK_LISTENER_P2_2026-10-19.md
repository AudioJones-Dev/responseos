## Prepared changes

Startup carrier audio is intentionally ineligible until configuration admission. During the asynchronous database claim/socket startup and configuration acknowledgment, the listener drops media immediately, retaining only three monotonic ordering counters. It validates stream identity, frame shape, mono PCMU payload size and the existing frame-size bound. Control events retain the existing bounded queue and startup deadline. The bridge receives the high-water counters before admission; discarded payloads are never replayed. Fresh media starts after the last discarded chunk. Delayed-claim and delayed-configuration real-socket regressions are drafted with 100 startup frames and a distinct first admitted payload.

Operator termination suppression is derived from the exact retained hangup command plus its operator request audit, never from a stop-reason string. The existing operator reservation transaction invokes a database-only callback to close Grok admission atomically with its durable command/audit. Provider I/O remains outside locks. If reservation refuses, times out or rolls back, the final stop leaves automatic termination available. A queued automatic claim observed after a durable operator reservation is consumed as disabled, never reset or sent. Already consumed automatic commands remain consumed: the previously approved explicit operator fallback is still a distinct one-shot authority, so it may send once after an earlier automatic attempt. No retry or eligibility override is introduced. Authenticated terminal proof without an operator reservation consumes any newly queued carrier claim as disabled. Draft regressions cover refusal, lock timeout, reservation rollback, competing dispatch/duplicate operator requests and preexisting authenticated terminal proof.

The watchdog loop treats returned session failures as alerts while retaining its one-second scheduling delay. Only a thrown whole-sweep failure increases global backoff. A successful sweep resets that backoff even if individual sessions failed. One-shot execution still reports unhealthy session results. Injected sweep/pause regressions check cadence, backoff reset, the 30-second cap and one-shot status; they have not run.
